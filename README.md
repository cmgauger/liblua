# liblua

A package of the Lua language as an embeddable library, with makefile and Visual
Studio solution, for local use (as a git submodule) to avoid linking against the
system supplied library (if there is one).

This repository is __not affiliated__ with Lua team at PUC-Rio, and the version
of Lua contained within is updated manually.

The official release of Lua, including the standalone interpreter and compiler
code which is __not__ included in this repository, may be found at:

* [Lua](https://www.lua.org/)

Please support the official release.
